clickzauber Zum Konfigurator
Einbau-Anleitung

Mit Website eine Zeile Code. Ohne Website ein Link.

Nach dem Speichern zeigt Ihnen der Konfigurator beides: Ihre persönliche Code-Zeile und die fertige Seite mit Link und QR-Code. Sie brauchen nur eines von beidem — welches, entscheidet Ihre Website.

Ihre Zeile — Beispiel
<script src="https://clickzauber-api.vercel.app/w.js" data-cz="ihre-widget-id" async></script>

Ihre echte Zeile enthält Ihre eigene Widget-Kennung. Sie finden sie im Konfigurator unter „Einbauen & teilen".

Keine Website? Dann sind Sie in einer Minute fertig.

Ihr Formular hat eine eigene fertige Seite bei uns — unter einer Adresse wie clickzauber-api.vercel.app/f/ihre-kennung. Die steht sofort bereit, ohne dass Sie irgendwo Code einfügen.

  • Instagram — Link in die Bio. Wer darauf tippt, landet direkt im Formular.
  • Story — mit der Link-Funktion verknüpfen, dann fragt man per Wischen an.
  • WhatsApp — den Link an jeden schicken, der sich meldet, statt zwanzig Fragen zu tippen.
  • QR-Code — im Cockpit als Bilddatei herunterladen, auf Aufsteller, Flyer oder Messestand drucken.

Alle Anfragen landen im selben Cockpit wie beim Einbau per Code. Sie sehen dort auch, über welchen Weg jemand gekommen ist.

Mit Website: Welches System nutzen Sie?

Prüfen, ob es läuft

  • Seite im privaten Fenster öffnenSo sehen Sie die Seite wie ein Gast — ohne zwischengespeicherte alte Version.
  • Widget erscheint an der richtigen StelleEs steht genau dort, wo Sie die Zeile eingefügt haben. Zu weit oben oder unten? Zeile verschieben.
  • Eine Testanfrage abschickenFüllen Sie das Widget einmal selbst aus. Die Anfrage muss im Cockpit stehen und als E-Mail ankommen.
  • Am Handy ansehenDie meisten Brautpaare suchen abends auf dem Sofa. Das Widget passt sich an, prüfen Sie es trotzdem einmal.

Wenn etwas nicht klappt

Das Widget erscheint nicht

Drei häufige Ursachen: Die Zeile wurde in ein Textfeld statt in ein HTML-/Code-Element eingefügt — viele Baukästen zeigen den Code dann als sichtbaren Text an. Oder die Seite wurde nach dem Einfügen nicht veröffentlicht. Oder Ihr Browser zeigt eine gespeicherte alte Version: einmal mit Strg+F5 (Mac: Cmd+Shift+R) neu laden.

Ich sehe den Code als Text auf der Seite

Dann sitzt die Zeile in einem normalen Textblock. Löschen Sie sie dort und fügen Sie stattdessen ein Element für eigenen Code ein — es heißt je nach System „Individuelles HTML", „Code einbetten", „Embed" oder „Code-Block".

Das Widget ist da, aber die Anfrage kommt nicht an

Prüfen Sie im Cockpit unter Einstellungen, ob Ihre Empfänger-Adresse stimmt, und schauen Sie in den Spam-Ordner. Kommt die Anfrage im Cockpit an, aber nicht per E-Mail, liegt es fast immer am Spam-Filter — markieren Sie die erste Mail als „Kein Spam".

Kann ich das Widget später verschieben oder ändern?

Ja. Design, Fragen, Preise und freie Termine ändern Sie im Cockpit, die Änderung ist sofort auf Ihrer Website sichtbar — den Code müssen Sie dafür nicht anfassen. Nur wenn das Widget an einer anderen Stelle der Seite stehen soll, verschieben Sie die Zeile.

Kann ich Link und Code gleichzeitig nutzen?

Ja, und das ist oft sinnvoll. Das Formular steht dann fest auf Ihrer Website und Sie teilen zusätzlich den Link auf Instagram oder als QR-Code. Es ist dasselbe Formular, alle Anfragen laufen in dasselbe Cockpit. Im Cockpit sehen Sie, über welchen Weg jemand gekommen ist.
